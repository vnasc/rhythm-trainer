# Rhythm Trainer (standalone browser prototype)

This is a self-contained HTML/JavaScript version of the single-lane audio-onset trainer. It includes an AudioWorklet onset detector, rhythm grid, hit/early/late feedback, browser-generated metronome and confirmation clicks, timing histogram, training graph and settings persistence.

## Audio notes

- Browser capture requests echo cancellation, noise suppression, and automatic gain control off, but the browser/driver may not honor every request.
- Browser input monitoring is off by default because it adds latency. For best playing feel, use the interface's direct monitoring/headphones. The metronome and hit-confirmation clicks are generated by the page.
- The browser’s audio-device/output latency can differ from Reaper; use **Latency compensation** to align hit judgments.
- The detector is the current transient/envelope-based audio-onset path. This first page does not yet include Reaper transport sync or the experimental pitch-change tracker.
